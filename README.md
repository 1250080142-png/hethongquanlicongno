HỆ THỐNG QUẢN LÍ HÓA NỢ VÀ CÔNG NỢ PHẢI THU
Các bước để có thể chạy được trang web:
Bước 1: git pull code từ trên github về máy tính cá nhân
Bước 2: Mở vào thư mục BCCK để vào thư mục database lấy code cơ sở dữ liệu 
Bước 3: Mở SQL SERVER -> chạy từng file trong thư mục database
Bước 4: Vào môi trường chuẩn bị chạy code mở file DemoApplication.java lên để chạy backend
Bước 5: Mở thêm 1 tab terminal để chạy lệnh npm start để chạy frontend
Bước 6: Đăng nhập vào web với các tài khoản như sau:
- Tài khoản khách hàng: Pho123
- Mật khẩu: Abc@123
- Tài khoản Admin: admin
- Mật khẩu: admin123
