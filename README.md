3. **Bước 3:** Mở **SQL Server Management Studio** -> Chạy lần lượt từng file script trong thư mục `database`.
4. **Bước 4:** Mở môi trường lập trình, tìm và mở file `DemoApplication.java` để khởi chạy **Backend**.
5. **Bước 5:** Mở thêm một tab terminal tại thư mục frontend và chạy lệnh:
